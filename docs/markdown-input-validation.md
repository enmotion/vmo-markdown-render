# MarkdownInput 验证记录

日期：2026-10-22。实现协议见 [MarkdownInput API](./api/markdown-input.md)。

## 本次交付

- 聊天 Markdown 源码编辑，代码区域等宽显示、列表续行，不转换成文档富文本块。
- 外部多触发符、外部候选与远程加载状态；支持键盘导航、禁用项和候选内容插槽。
- 带稳定身份的 mention 原子标签、关闭/退格删除、撤销重做和结构化剪贴板。

- 不提供媒体容器、文件处理或正文组件注入。
- 开发首页默认聊天工作台，可切换已有 Markdown 展示工作台；`/?view=render` 可直达展示。

## 原有 render 回归情况

完整浏览器回归中的 render 用例 11/14 通过，三个失败分别为：info 颜色断言、四种语义色差异断言、Mermaid 拖拽矩阵断言。在 `/tmp` 中导出修改前 HEAD 的副本，独立端口重新运行这三个用例，均在相同断言处失败。本次没有改变其配色或拖拽行为，也没有改写断言来隐藏失败；仅将 renderer 用例入口调整为 `/?view=render` 以适配新增的工作台切换。

## 分类快捷键升级验证

- 默认关闭字符触发，外部配置 Ctrl/Alt/Shift/Meta 与单字符键的精确组合，每个组合绑定 source。演示支持修改修饰键和分类字符键。
- 搜索、选中、标签持久化及剪贴板保留 source；即使 filterOption=false，其他分类和未分类候选也不会展示。
- 新增快捷键匹配与混合分类过滤单测；输入浏览器用例更新为 5 项，覆盖无修饰键/额外修饰键不触发、不同分类、关键词替换、动态重新绑定与输入法期间不触发。

## 加号与本地附件预览

聊天工作台新增“＋”入口：分类引用与添加附件。引用使用 openMention/captureSelection 保留原选区，手机候选面板使用独立搜索框；聊天顶部附件区支持图片缩略图、文件卡片与删除，发送演示消息后保留附件。附件为本地预览，不执行网络上传。

浏览器用例扩展为 7 项，新增光标中间插入、文件选择器、顶部图片/文件预览、删除与发送，以及窄屏触屏面板。软键盘避让使用 visualViewport，真实手机设备仍需试用。

## 字符串公共接口升级

v-model、update:modelValue、submit 以及 getValue/getText 的常规输出均为字符串。mentionCodec 支持替换协议，setValue 可将外部文本恢复为内部节点并同步 v-model。默认协议保留 mention 身份并处理保留标记与连续反斜线转义。新增可逆协议、无效标记、定制编解码、错误降级、setter 与普通回写不重建 DOM 等测试，已有 7 项浏览器输入测试全部通过。演示页改为保存字符串并分别显示发送文本和可恢复文本。

## 显式 getter/setter 与命名添加插槽（2026-10-23）

公共转换配置更新为 getter/setter 函数，实例暴露同名 getter()/setter(text)，原 getValue/setValue 为兼容别名。演示草稿保存恢复直接使用明确实例方法。add/actions 为命名作用域插槽，未提供时不渲染工具栏或按钮；宿主定义加号与菜单，作用域提供 captureSelection/openMention 及状态。新增空组件无按钮、定制插槽与只读状态传递测试，原有输入浏览器回归继续覆盖加号引用与附件。

## 纯输入职责收敛（2026-10-24）

移除工具栏插槽与发送策略，输入组件默认 Enter 换行，宿主可通过 enter 事件 preventDefault 接管。新增测试确认即使传入旧 add/actions/footer 插槽也不会渲染按钮或工具栏、默认换行、宿主取消默认编辑以及无 submit 方法/事件。演示工具栏与发送策略均移到组件外部，原有 7 项浏览器测试通过，覆盖外部按钮发送、键盘发送、引用与附件。

## 严格空格字符触发与临时过滤

新增 mentionTriggers 多字符分类配置，与组合键共存。移除扫描已有正文的旧触发逻辑，提示字符仅在直接输入且前一字符为半角空格时唤起。两入口均将临时查询与内部文档隔离，拼音首字母匹配由演示页的外部 filterOption 实现。

新增触发边界纯函数测试及三项浏览器测试，覆盖行首/普通文字/换行/制表/全角空格/代码不触发、拼音过滤不污染正文、空格消费、退出后普通输入、多分类、组合键、临时退格、输入法、失焦、外部替换与撤销重做不重新唤起。输入浏览器用例共 10 项，全部通过。
