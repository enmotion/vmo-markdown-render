## 始终直接渲染更新

按最新确认取消整行源码切换，移除 selectionchange 显示监听。完整结构始终渲染，破坏结构后显示残缺原文，撤销恢复排版。更新源码光标映射，避免尾部符号隐藏后追加文字进入不可见节点。浏览器覆盖逐字闭合、末尾追加、Backspace 破坏删除线/粗体、撤销恢复、焦点变化不显露符号，以及格式内的 mention 插入。

补充引用兼容：行首 `>引用` 与 `> 引用` 均识别，列表仍要求分隔空白。新增浏览器回归逐字输入 `~~删除内容~~` 与无空格引用，确认即时排版及源码保留；15 项输入浏览器测试通过。标准双半角波浪号删除线未复现失效，其他输入写法待实际原文确认。


按最新约定精简输入语法：仅保留星号粗体/斜体、双波浪号删除线、短横线加半角空格无序列表及有序列表。移除下划线强调、代码与引用；加号/星号不再识别为列表或自动续行。反引号不再限制 mention，enter 的兼容字段 inCode 固定 false。本约定取代此前更广的输入语法支持范围；不改变 MarkdownRender。


输入语法进一步移除删除线支持：半角 `~~内容~~` 和全角 `～～内容～～` 均保留普通文字。仅支持星号粗体/斜体、短横线无序列表和有序列表。


节点协议更新：内部文本为 {type:"text",content:string}，mention 为 {type:"mention",content:{label,id,type?,data?}}。默认 getter/v-model 输出数组，文字保留节点结构，mention 展平为 {label,id,type?}，不包含 data、不进行 URI 编码；默认 setter 恢复相同数组，字符串按纯文字导入。转换函数均可省略，getText 独立返回按 label 拼接的文字。此约定取代早期默认字符串编码协议。
